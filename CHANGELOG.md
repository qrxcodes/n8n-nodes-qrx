# Changelog

## 0.1.0

- QRX node: Create, Get, Get Many and Change Link for QR codes (changing a code's link is on a paid plan), and Get for the account.
- Create waits until the code is ready, with a timeout, and can download the PNG into a binary field.
- QRX Trigger: starts a workflow when a new QR code is ready.
- QRX API credential (API key).
